# Google Play assets

## Required before publication

- Prepare a current 1024 x 500 px RGB PNG feature graphic. The previous `feature-graphic.png` was removed as outdated; no replacement is checked in.
- The launcher icon is generated from the production adaptive icon resources during the Android build.

## Required from the final signed build

- Capture the required phone screenshots from a Play-delivered, signed release build on a real device.
- Show only states that were actually exercised. Do not use generated UI images as evidence of app behavior.
- Recheck every uploaded image in the Play Console preview before publishing.

The upload itself and any Play Console crop or compression remain external release gates.
